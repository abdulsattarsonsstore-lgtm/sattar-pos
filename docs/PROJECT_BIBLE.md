# Abdul Sattar Sons POS

> A professional cloud-based Point of Sale (POS) system built for Abdul Sattar Sons Paint, Sanitary, Hardware & Building Material Store.

---

# Vision

Create a modern, fast and reliable POS system that can replace manual billing, inventory registers and handwritten customer credit records.

The software should be simple enough for shop staff to learn quickly while powerful enough to support future business growth.
